# Microbiome Grant Tracker

A public tracker of upcoming microbiome research funding calls, maintained by the [Langille Lab](https://morganlangille.com/) at Dalhousie University.

**Focus:** Canadian funders and human microbiome research, plus open Canadian programs that support microbiome work (CIHR Project Grant, NSERC Discovery, NFRF, etc.).

For each call the tracker lists the funder, deadlines, funding amount, duration and a link to the official call. Listings are refreshed weekly; always confirm details on the funder's page before applying.
